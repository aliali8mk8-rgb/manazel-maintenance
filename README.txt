موقع شركة منازل للصيانة - نسخة محسنة لإعلانات Google Ads

المحتوى:
- index.html: الصفحة الرئيسية
- privacy.html: سياسة الخصوصية
- style.css: التصميم المتجاوب
- script.js: وظائف بسيطة
- images/: صور الصيانة التي أرسلها المستخدم، محفوظة داخل الموقع

ملاحظات:
1) لا توجد أدوات تتبع أو Google Tag مضافة لأن رقم القياس/Tag ID لم يتم توفيره.
2) بعد نشر الموقع، اختبر الاتصال وواتساب من الهاتف.
3) عند إضافة Google Ads conversion tracking لاحقاً، أضف كود Google Tag الرسمي من حسابك فقط.
4) استبدل رابط canonical الفارغ في index.html بالرابط النهائي للموقع بعد إنشاء GitHub Pages إذا رغبت في استخدامه لتحسين SEO.
